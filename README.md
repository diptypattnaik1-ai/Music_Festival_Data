# 🎵 Music Festival and Artist Popularity Analysis

## 📌 Project Overview

This project focuses on analyzing music festival data and artist popularity using Microsoft Power BI. The dashboard helps explore festival trends, compare artist popularity, and understand the data through visualizations.

## 🎯 Project Objectives

- Analyze music festival data.
- Explore artist popularity.
- Identify trends and patterns in festival data.
- Present meaningful insights through interactive visualizations.
- Make data easier to understand using Power BI dashboards.

## 🛠️ Tools and Technologies

- Microsoft Power BI
- Power Query
- Data Visualization
- Data Analysis
